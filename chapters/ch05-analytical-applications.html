5.1 Mean Value Theorem (MVT)

✅ Mean Value Theorem
If $f$ is:
  • continuous on the closed interval $[a,b]$, and
  • differentiable on the open interval $(a,b)$,
then there exists at least one $c \in (a,b)$ such that: $$f'(c) = \frac{f(b) - f(a)}{b - a}$$ The instantaneous rate of change equals the average rate of change at some point.
Figure 5.1 Mean Value Theorem. Somewhere between $a$ and $b$ the instantaneous rate equals the average rate: the tangent at $c$ is parallel to the secant.
📌 Rolle's Theorem (Special Case)
If additionally $f(a) = f(b)$, then there exists $c \in (a,b)$ with $f'(c) = 0$ (a horizontal tangent).

5.2 Extreme Value Theorem (EVT)

✅ Extreme Value Theorem
If $f$ is continuous on $[a,b]$, then $f$ attains both an absolute maximum and an absolute minimum on $[a,b]$.

To find absolute extrema on $[a,b]$:

  1. Find all critical numbers in $(a,b)$ (where $f'(c) = 0$ or $f'(c)$ undefined).
  2. Evaluate $f$ at each critical number AND at the endpoints $a$ and $b$.
  3. The largest value is the absolute maximum; the smallest is the absolute minimum.

5.3 Critical Numbers & Local Extrema

📐 Critical Number
$c$ is a critical number of $f$ if $f'(c) = 0$ or $f'(c)$ does not exist (and $f(c)$ is defined). Local extrema can only occur at critical numbers.

Note: Not every critical number is a local extremum — it could be an inflection point.

5.4 First Derivative Test

✅ First Derivative Test
Suppose $c$ is a critical number of a continuous function $f$.
  • If $f'$ changes from positive to negative at $c$ → local maximum at $c$.
  • If $f'$ changes from negative to positive at $c$ → local minimum at $c$.
  • If $f'$ does not change sign at $c$ → no local extremum (could be inflection).
📌 Sign Chart Method
Draw a number line, mark critical numbers. Test one value in each interval to determine the sign of $f'$. Arrows: ↑ for $f'>0$, ↓ for $f'<0$. Local max at ↑↓ transition, local min at ↓↑ transition.
Figure 5.2 First Derivative Test. $f'$ changes $+\to-$ at $x=-1$ (local maximum) and $-\to+$ at $x=1$ (local minimum).

5.5 Concavity & Second Derivative Test

📐 Concavity
  • $f$ is concave up on $(a,b)$ if $f'' > 0$ on $(a,b)$ — graph "holds water" ∪
  • $f$ is concave down on $(a,b)$ if $f'' < 0$ on $(a,b)$ — graph "spills water" ∩
An inflection point is where the concavity changes. Candidate points: where $f'' = 0$ or $f''$ undefined — but must verify a sign change.
✅ Second Derivative Test
If $f'(c) = 0$ and $f''(c)$ exists:
  • $f''(c) > 0$ → $f$ concave up at $c$ → local minimum
  • $f''(c) < 0$ → $f$ concave down at $c$ → local maximum
  • $f''(c) = 0$ → inconclusive (use first derivative test)
Figure 5.3 Concavity. Tangent slopes decrease while the curve is concave down and increase while concave up; the sign change of $f''$ marks the inflection point.

5.6 Curve Sketching Checklist

  1. Domain — where is $f$ defined?
  2. Intercepts — $y$-intercept: $f(0)$. $x$-intercepts: $f(x) = 0$.
  3. Symmetry — even ($f(-x)=f(x)$), odd ($f(-x)=-f(x)$), or neither?
  4. Asymptotes — horizontal (limits at $\pm\infty$), vertical (where denominator = 0).
  5. Increasing/Decreasing — sign of $f'$; locate critical numbers.
  6. Local Extrema — apply first or second derivative test.
  7. Concavity — sign of $f''$; locate inflection points.
  8. Sketch — plot key points and connect with the behavior above.

5.7 Optimization

📐 Optimization Strategy
  1. Define variables and write the objective function to maximize/minimize.
  2. Use any constraint to reduce to one variable.
  3. Find critical numbers using $f' = 0$.
  4. Verify using first/second derivative test or endpoint analysis.
  5. Answer the question (include units).

Worked Examples

Example 1Applying the MVT

Verify the MVT applies to $f(x) = x^3 - x$ on $[0,2]$ and find the guaranteed $c$.

1
$f$ is a polynomial: continuous on $[0,2]$, differentiable on $(0,2)$. MVT applies.
2
Average rate: $\dfrac{f(2)-f(0)}{2-0} = \dfrac{(8-2)-0}{2} = \dfrac{6}{2} = 3$.
3
$f'(x) = 3x^2 - 1 = 3 \Rightarrow 3x^2 = 4 \Rightarrow x^2 = 4/3 \Rightarrow x = \dfrac{2}{\sqrt{3}} \approx 1.155$. This is in $(0,2)$ ✓. So $c = \dfrac{2}{\sqrt{3}} = \boxed{\dfrac{2\sqrt{3}}{3}}$.
Example 2Absolute Extrema on Closed Interval

Find the absolute max and min of $f(x) = x^3 - 3x^2 + 1$ on $[-1, 3]$.

1
$f'(x) = 3x^2 - 6x = 3x(x-2) = 0 \Rightarrow x = 0, 2$. Both in $[-1,3]$.
2
Evaluate at critical numbers and endpoints:
$f(-1) = -1-3+1 = -3$
$f(0) = 0-0+1 = 1$
$f(2) = 8-12+1 = -3$
$f(3) = 27-27+1 = 1$
3
Absolute max: $1$ at $x=0$ and $x=3$. Absolute min: $-3$ at $x=-1$ and $x=2$.
Example 3Full Curve Analysis

Analyze $f(x) = x^4 - 4x^3$: find local extrema, inflection points, and concavity.

1
$f'(x) = 4x^3 - 12x^2 = 4x^2(x-3)$. Critical: $x=0$ and $x=3$.
2
Sign of $f'$: $x<0$: $4(-)(-)= -$ (dec), $0<x<3$: $4(+)(-) = -$ (dec), $x>3$: $4(+)(+) = +$ (inc). First derivative test: $f'$ stays negative through $x=0$ → no extremum at $x=0$. $f'$ goes $-$ to $+$ at $x=3$ → local min at $x=3$, $f(3) = 81-108 = -27$.
3
$f''(x) = 12x^2 - 24x = 12x(x-2)$. $f''=0$ at $x=0$ and $x=2$. $f''<0$ on $(0,2)$ → concave down; $f''>0$ on $(-\infty,0)\cup(2,\infty)$ → concave up. Inflection points at $x=0$ ($y=0$) and $x=2$ ($y = 16-32 = -16$).
Example 4Optimization — Fence Problem

A farmer has 240 meters of fence to enclose a rectangular area, one side of which is a river (no fence needed on that side). What dimensions maximize the enclosed area?

1
Variables: let $x$ = length parallel to river, $y$ = width (two sides needed). Constraint: $x + 2y = 240$, so $x = 240 - 2y$.
2
Objective: $A = xy = (240-2y)y = 240y - 2y^2$.
3
$A'(y) = 240 - 4y = 0 \Rightarrow y = 60$. $A'' = -4 < 0$ → maximum.
4
$x = 240 - 120 = 120$ m, $y = 60$ m. $A_{\max} = 120 \times 60 = \boxed{7200 \text{ m}^2}$.
Example 5Optimization — Minimum Surface Area Box

An open-top box with a square base must hold a volume of 32 cm³. Find dimensions that minimize surface area.

1
Let base side $= x$, height $= h$. Volume: $x^2 h = 32 \Rightarrow h = 32/x^2$.
2
Surface area (open top): $S = x^2 + 4xh = x^2 + 4x \cdot \dfrac{32}{x^2} = x^2 + \dfrac{128}{x}$.
3
$S'(x) = 2x - \dfrac{128}{x^2} = 0 \Rightarrow 2x^3 = 128 \Rightarrow x^3 = 64 \Rightarrow x = 4$.
4
$h = 32/16 = 2$. $S''(x) = 2 + 256/x^3 > 0$ → minimum. Base: $4\times 4$ cm, height: 2 cm.
