The area between $y=x^2$ and $y=x$ on $[0,1]$ is
A $1/4$
B $1/3$
C $1/6$
D $1/2$
$\int_0^1(x-x^2)dx=\Big[\dfrac{x^2}{2}-\dfrac{x^3}{3}\Big]_0^1=\dfrac{1}{2}-\dfrac{1}{3}=\dfrac{1}{6}$.
2
The average value of $f(x)=x^2$ on $[0,3]$ is
A 3
B 9
C $3/2$
D $6$
$\bar{f}=\dfrac{1}{3-0}\int_0^3 x^2\,dx=\dfrac{1}{3}\Big[\dfrac{x^3}{3}\Big]_0^3=\dfrac{1}{3}\cdot9=3$.

The volume when $y=\sqrt{x}$, $0\le x\le4$, is rotated around the $x$-axis is
A $4\pi$
B $16\pi$
C $4$
D $8\pi$
Disk: $V=\pi\int_0^4(\sqrt{x})^2dx=\pi\int_0^4 x\,dx=\pi\Big[\dfrac{x^2}{2}\Big]_0^4=8\pi$.

The washer method formula for rotating $f(x)\ge g(x)\ge 0$ around the $x$-axis is
A $\pi\displaystyle\int_a^b[f(x)]^2dx$
B $\pi\displaystyle\int_a^b\!\left([f(x)]^2-[g(x)]^2\right)dx$
C $\pi\displaystyle\int_a^b[f(x)-g(x)]^2dx$
D $2\pi\displaystyle\int_a^b xf(x)\,dx$
Washer: $V=\pi\int_a^b(R^2-r^2)dx$ where $R=f(x)$ (outer) and $r=g(x)$ (inner). Option C is wrong because $(f-g)^2\ne f^2-g^2$.
5
Area enclosed by $y=\cos x$ and $y=\sin x$ on $[0,\pi/4]$ is
A $1$
B $\sqrt{2}$
C $\sqrt{2}-1$
D $\dfrac{1}{2}$
$\cos x\ge\sin x$ on $[0,\pi/4]$. $\int_0^{\pi/4}(\cos x-\sin x)dx=[\sin x+\cos x]_0^{\pi/4}=\sqrt{2}-1$.
6
Rotating $y=2$, $y=0$, $x=0$, $x=3$ around the $x$-axis gives volume
A $12\pi$
B $4\pi$
C $6\pi$
D $24\pi$
Disk: $V=\pi\int_0^3 4\,dx=4\pi(3)=12\pi$. (A cylinder of radius 2 and length 3.)
7
The arc length of $y=\dfrac{2}{3}x^{3/2}$ from $x=0$ to $x=3$ is
A $8/3$
B $2\sqrt{3}$
C 4
D $\dfrac{14}{3}$
$y'=x^{1/2}$. $L=\int_0^3\sqrt{1+x}\,dx=\Big[\dfrac{2}{3}(1+x)^{3/2}\Big]_0^3=\dfrac{2}{3}(8-1)=\dfrac{14}{3}$.
8
Volume by shell method rotating $y=x^2$, $0\le x\le 2$ around the $y$-axis is
A $4\pi$
B $8\pi$
C $16\pi$
D $2\pi$
$V=2\pi\int_0^2 x\cdot x^2\,dx=2\pi\int_0^2 x^3\,dx=2\pi\Big[\dfrac{x^4}{4}\Big]_0^2=2\pi\cdot4=8\pi$.

The MVT for Integrals guarantees that there exists $c\in[a,b]$ such that
A $f'(c)=\dfrac{f(b)-f(a)}{b-a}$
B $f(c)=f(a)+f(b)$
C $f(c)=\dfrac{1}{b-a}\int_a^b f(x)\,dx$
D $\int_a^b f(x)\,dx=f(c)$
MVT for Integrals: if $f$ is continuous on $[a,b]$, $\exists c\in[a,b]$ with $f(c)=\dfrac{1}{b-a}\int_a^b f\,dx$ (the average value).

Area between $y=4-x^2$ and the $x$-axis is
A $32/3$
B 8
C 16/3
D 4
$4-x^2\ge0$ on $[-2,2]$. $\int_{-2}^2(4-x^2)dx=\Big[4x-\dfrac{x^3}{3}\Big]_{-2}^2=\left(8-\dfrac{8}{3}\right)-\left(-8+\dfrac{8}{3}\right)=\dfrac{32}{3}$.

Volume when $y=x$, $0\le x\le3$, is rotated around the $x$-axis using the disk method is
A $27$
B $9\pi/2$
C $9\pi$
D $9\pi$
$V=\pi\int_0^3 x^2\,dx=\pi\Big[\dfrac{x^3}{3}\Big]_0^3=9\pi$.

Which integral gives the area between $y=x^3$ and $y=x$ on $[-1,1]$?
A $\displaystyle\int_{-1}^1(x^3-x)\,dx$
B $\displaystyle\int_{-1}^1|x^3-x|\,dx$
C $\displaystyle\int_{-1}^1 x^3\,dx$
D $\displaystyle\int_0^1(x-x^3)\,dx$
Area between curves always uses the absolute value (or splits at intersections). $\int_{-1}^1|x^3-x|\,dx$ correctly accounts for sign changes.

The average value of $f(x)=\sin x$ on $[0,\pi]$ is
A 0
B 1
C $2/\pi$
D $\pi/2$
$\bar{f}=\dfrac{1}{\pi}\int_0^\pi\sin x\,dx=\dfrac{1}{\pi}[-\cos x]_0^\pi=\dfrac{1}{\pi}(1+1)=\dfrac{2}{\pi}$.

The shell method formula for rotation around the $y$-axis is
A $\pi\displaystyle\int_a^b[f(x)]^2dx$
B $\pi\displaystyle\int_a^b x^2\,dx$

Volume using washers: region between $y=x$ and $y=x^2$ on $[0,1]$ rotated about $x$-axis.
A $\pi/5$
B $2\pi/15$
C $\pi/3$
D $\pi/6$
$V=\pi\int_0^1(x^2-(x^2)^2)dx=\pi\int_0^1(x^2-x^4)dx=\pi\Big[\dfrac{x^3}{3}-\dfrac{x^5}{5}\Big]_0^1=\pi\left(\dfrac{1}{3}-\dfrac{1}{5}\right)=\dfrac{2\pi}{15}$.

The arc length formula for $y=f(x)$ on $[a,b]$ is
A $\displaystyle\int_a^b\sqrt{1+[f'(x)]^2}\,dx$
B $\displaystyle\int_a^b [f'(x)]^2\,dx$
C $\displaystyle\int_a^b |f'(x)|\,dx$
D $\displaystyle\int_a^b\sqrt{f(x)}\,dx$
Arc length: $L=\int_a^b\sqrt{1+(f'(x))^2}\,dx$. Derived from the Pythagorean theorem on infinitesimal segments.
19
If $f(x)=4$ on $[1,5]$, the average value of $f$ on $[1,5]$ is
A 16
B 8
C 2
D 4
Average $=\dfrac{1}{5-1}\int_1^5 4\,dx=\dfrac{1}{4}\cdot16=4$. A constant function's average value is itself.

When is the shell method preferred over the disk/washer method?
A Always
B When rotating around the $x$-axis
C When the region is described as a function of $x$ but rotated around the $y$-axis
D When $f(x)\ge 0$ only
Shell is preferred when the axis of rotation is parallel to the axis of integration — e.g., region described in $x$ but rotated around $y$-axis, avoiding the need to re-express the function in terms of $y$.
