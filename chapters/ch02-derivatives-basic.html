2.1 The Limit Definition of the Derivative

The derivative of $f$ at $x = a$ measures the instantaneous rate of change — the slope of the tangent line to the curve at that point.

📐 Definition — Derivative at a Point
$$f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}$$ provided this limit exists. The expression $\dfrac{f(a+h)-f(a)}{h}$ is called the difference quotient.
📐 Alternate Form
$$f'(a) = \lim_{x \to a} \frac{f(x) - f(a)}{x - a}$$

The derivative function is obtained by treating $a$ as a variable $x$:

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

Figure 2.1 — As $h \to 0$, the secant line approaches the tangent line. The slope of the tangent is $f'(x)$.

2.3 Basic Differentiation Rules

✅ Core Differentiation Rules
RuleFormulaExample
Constant$\dfrac{d}{dx}[c] = 0$$\dfrac{d}{dx}[7] = 0$
Power$\dfrac{d}{dx}[x^n] = nx^{n-1}$$\dfrac{d}{dx}[x^5] = 5x^4$
Constant Multiple$\dfrac{d}{dx}[cf] = cf'$$\dfrac{d}{dx}[3x^4] = 12x^3$
Sum / Difference$(f \pm g)' = f' \pm g'$$\dfrac{d}{dx}[x^3 + x] = 3x^2 + 1$
Product$(fg)' = f'g + fg'$$\dfrac{d}{dx}[x^2\sin x] = 2x\sin x + x^2\cos x$
Quotient$\left(\dfrac{f}{g}\right)' = \dfrac{f'g - fg'}{g^2}$$\dfrac{d}{dx}\!\left[\dfrac{x}{x+1}\right] = \dfrac{1}{(x+1)^2}$
📌 Power Rule for All Reals
The power rule $\dfrac{d}{dx}[x^n] = nx^{n-1}$ works for any real number $n$ (including negative and fractional exponents). $$\frac{d}{dx}[x^{-3}] = -3x^{-4} \qquad \frac{d}{dx}[\sqrt{x}] = \frac{d}{dx}[x^{1/2}] = \frac{1}{2}x^{-1/2} = \frac{1}{2\sqrt{x}}$$

The Product Rule — Memory Device

Think of it as: "derivative of first times second, plus first times derivative of second."

$$(fg)' = \underbrace{f'}_{\text{d first}} \cdot \underbrace{g}_{\text{second}} \;+\; \underbrace{f}_{\text{first}} \cdot \underbrace{g'}_{\text{d second}}$$

The Quotient Rule — Memory Device

"Low d-high minus high d-low, over low squared." ($\text{low} = g$, $\text{high} = f$)

$$\left(\frac{f}{g}\right)' = \frac{g \cdot f' - f \cdot g'}{g^2}$$

2.4 Derivatives of Trigonometric Functions

✅ Trig Derivatives (Memorize All Six)

$\dfrac{d}{dx}[\sin x] = \cos x$

$\dfrac{d}{dx}[\cos x] = -\sin x$

$\dfrac{d}{dx}[\tan x] = \sec^2 x$

$\dfrac{d}{dx}[\csc x] = -\csc x\cot x$

$\dfrac{d}{dx}[\sec x] = \sec x\tan x$

$\dfrac{d}{dx}[\cot x] = -\csc^2 x$

📌 Pattern
The "co-functions" (cosine, cosecant, cotangent) always pick up a negative sign. Pair them: $\sin\leftrightarrow\cos$, $\tan\leftrightarrow\sec$, $\cot\leftrightarrow\csc$.

2.5 Derivatives of Exponential and Logarithmic Functions

✅ Exponential and Log Derivatives
FunctionDerivative
$e^x$$e^x$
$a^x$ ($a>0, a\ne1$)$a^x \ln a$
$\ln x$ ($x>0$)$\dfrac{1}{x}$
$\log_a x$$\dfrac{1}{x\ln a}$
📌 Why $\frac{d}{dx}[e^x] = e^x$?
$e$ is defined precisely so that $\lim_{h\to 0}\frac{e^h - 1}{h} = 1$. This makes $e^x$ the unique function equal to its own derivative.

2.6 Differentiability vs. Continuity

✅ Key Relationship
Differentiability implies continuity.
If $f'(a)$ exists, then $f$ is continuous at $a$.

The converse is false: continuity does not imply differentiability.

Where Differentiability Fails (but the function is continuous)

  • Corner/cusp: $f(x) = |x|$ at $x=0$ — left and right derivatives exist but differ.
  • Vertical tangent: $f(x) = x^{1/3}$ at $x=0$ — slope is $\pm\infty$.
$$\frac{d}{dx}[|x|] = \frac{x}{|x|} = \begin{cases} 1 & x > 0 \\ -1 & x < 0 \end{cases} \quad \text{undefined at } x=0$$

Worked Examples

Example 1 Using the Limit Definition

Use the limit definition to find $f'(x)$ for $f(x) = x^2 - 3x$.

1
Write the difference quotient: $$\frac{f(x+h)-f(x)}{h} = \frac{[(x+h)^2 - 3(x+h)] - [x^2-3x]}{h}$$
2
Expand: $= \dfrac{x^2+2xh+h^2 - 3x-3h - x^2+3x}{h} = \dfrac{2xh + h^2 - 3h}{h}$
3
Factor and cancel $h$: $= \dfrac{h(2x+h-3)}{h} = 2x + h - 3$
4
Take the limit: $f'(x) = \lim_{h\to 0}(2x+h-3) = \boxed{2x-3}$
Example 2 Differentiating a Polynomial

Find $\dfrac{d}{dx}\!\left[5x^4 - \dfrac{3}{x^2} + 7\sqrt{x} - 2\right]$.

1
Rewrite as powers: $5x^4 - 3x^{-2} + 7x^{1/2} - 2$
2
Apply power rule term by term: $$= 20x^3 - 3(-2)x^{-3} + 7 \cdot \tfrac{1}{2}x^{-1/2} - 0$$
3
$$= \boxed{20x^3 + \frac{6}{x^3} + \frac{7}{2\sqrt{x}}}$$
Example 3 Product Rule

Differentiate $g(x) = x^3 e^x$.

1
Let $f = x^3$, $\;g_2 = e^x$. Then $f' = 3x^2$, $\;g_2' = e^x$.
2
$(fg_2)' = f'g_2 + fg_2' = 3x^2 e^x + x^3 e^x = \boxed{e^x(3x^2 + x^3)} = \boxed{x^2 e^x(3+x)}$
Example 4 Quotient Rule

Find $h'(x)$ for $h(x) = \dfrac{\sin x}{x^2 + 1}$.

1
$f = \sin x$, $\;g = x^2+1$. Then $f' = \cos x$, $\;g' = 2x$.
2
$$h'(x) = \frac{g f' - f g'}{g^2} = \frac{(x^2+1)\cos x - \sin x \cdot 2x}{(x^2+1)^2} = \boxed{\frac{(x^2+1)\cos x - 2x\sin x}{(x^2+1)^2}}$$
Example 5 Trig + Product

Find $\dfrac{d}{dx}[x^2 \tan x]$.

1
$f = x^2$, $g = \tan x$. $f' = 2x$, $g' = \sec^2 x$.
2
$(fg)' = 2x\tan x + x^2\sec^2 x = \boxed{x(2\tan x + x\sec^2 x)}$
Example 6 Equation of Tangent Line

Find the equation of the tangent line to $f(x) = x^3 - 2x$ at $x = 2$.

1
Find the point: $f(2) = 8 - 4 = 4$. Point: $(2, 4)$.
2
Find the slope: $f'(x) = 3x^2 - 2$, so $f'(2) = 12 - 2 = 10$.
3
Point-slope form: $y - 4 = 10(x - 2)$, so $\boxed{y = 10x - 16}$.
