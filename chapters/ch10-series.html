10.1 Sequences

An infinite sequence is an ordered list $\{a_n\}_{n=1}^\infty$. We say $\{a_n\}$ converges to $L$ if $\displaystyle\lim_{n\to\infty} a_n = L$; otherwise it diverges.

✅ Sequence Limit Theorems
  • If $\lim_{n\to\infty} |a_n| = 0$, then $\lim_{n\to\infty} a_n = 0$.
  • $\lim_{n\to\infty} r^n = 0$ if $|r| < 1$; diverges if $|r| > 1$.
  • Squeeze theorem applies to sequences.
  • $\lim_{n\to\infty} n^{1/n} = 1$, $\;\lim_{n\to\infty}\dfrac{\ln n}{n} = 0$.

10.2 Series and Partial Sums

An infinite series is $\displaystyle\sum_{n=1}^\infty a_n = a_1 + a_2 + a_3 + \cdots$. The $N$-th partial sum is $S_N = \displaystyle\sum_{n=1}^N a_n$. The series converges to $S$ if $\lim_{N\to\infty} S_N = S$.

✅ Geometric Series
$$\sum_{n=0}^\infty ar^n = \frac{a}{1-r} \quad \text{if } |r| < 1, \quad \text{diverges if } |r| \ge 1$$ This is the most important series to know.
✅ p-Series
$$\sum_{n=1}^\infty \frac{1}{n^p} \begin{cases} \text{converges} & p > 1 \\ \text{diverges} & p \le 1 \end{cases}$$ Special case $p=1$: the harmonic series $\sum 1/n$ diverges.
✅ Divergence Test (Test for Divergence)
If $\lim_{n\to\infty} a_n \ne 0$ (or doesn't exist), then $\sum a_n$ diverges.
Warning: If $\lim a_n = 0$, the series may converge OR diverge — this test is inconclusive.

10.4 Alternating Series

✅ Alternating Series Test (Leibniz Test)
If $\sum (-1)^n b_n$ (with $b_n > 0$) satisfies:
  1. $b_{n+1} \le b_n$ (decreasing)
  2. $\lim_{n\to\infty} b_n = 0$
then the series converges.
📐 Absolute vs. Conditional Convergence
  • Absolutely convergent: $\sum |a_n|$ converges. (Absolute convergence implies convergence.)
  • Conditionally convergent: $\sum a_n$ converges but $\sum |a_n|$ diverges.
Example: $\sum \dfrac{(-1)^{n+1}}{n}$ converges conditionally (alternating harmonic series).
✅ Alternating Series Estimation Theorem
For a convergent alternating series, the error from using $S_N$ to approximate $S$ satisfies: $$|S - S_N| \le b_{N+1}$$ The error is bounded by the first omitted term.

10.5 Power Series & Radius of Convergence

📐 Power Series
$$\sum_{n=0}^\infty c_n(x-a)^n = c_0 + c_1(x-a) + c_2(x-a)^2 + \cdots$$ Centered at $x = a$.
📐 Radius and Interval of Convergence
  • Radius of convergence $R$: found using the ratio test: $R = \lim_{n\to\infty}\left|\dfrac{c_n}{c_{n+1}}\right|$.
  • Converges absolutely for $|x-a| < R$, diverges for $|x-a| > R$.
  • Must check endpoints separately (not covered by ratio test).
  • Interval of convergence: the set of all $x$ for which the series converges.
📌 Operations on Power Series
Within the radius of convergence, a power series can be differentiated and integrated term by term: $$\frac{d}{dx}\left[\sum_{n=0}^\infty c_n x^n\right] = \sum_{n=1}^\infty n c_n x^{n-1} \qquad \int \sum_{n=0}^\infty c_n x^n\,dx = \sum_{n=0}^\infty \frac{c_n x^{n+1}}{n+1} + C$$

10.6 Taylor and Maclaurin Series

📐 Taylor Series
If $f$ has derivatives of all orders at $x = a$: $$f(x) = \sum_{n=0}^\infty \frac{f^{(n)}(a)}{n!}(x-a)^n = f(a) + f'(a)(x-a) + \frac{f''(a)}{2!}(x-a)^2 + \cdots$$ When $a = 0$: Maclaurin series.
✅ Key Maclaurin Series (Memorize)

$e^x$$\displaystyle\sum_{n=0}^\infty \dfrac{x^n}{n!} = 1 + x + \dfrac{x^2}{2!} + \dfrac{x^3}{3!}+\cdots$all $x$
$\sin x$$\displaystyle\sum_{n=0}^\infty \dfrac{(-1)^n x^{2n+1}}{(2n+1)!} = x - \dfrac{x^3}{6}+\dfrac{x^5}{120}-\cdots$all $x$

10.7 Lagrange Error Bound

✅ Lagrange Error Bound
If $T_n(x)$ is the $n$-th degree Taylor polynomial of $f$ centered at $a$, then the remainder $R_n(x) = f(x) - T_n(x)$ satisfies: $$|R_n(x)| \le \frac{M}{(n+1)!}|x-a|^{n+1}$$ where $M$ is the maximum value of $|f^{(n+1)}(t)|$ for $t$ between $a$ and $x$.
📌 Strategy for Finding $M$
  1. Find $f^{(n+1)}(x)$ (one more derivative than the polynomial degree).
  2. Find the maximum of $|f^{(n+1)}(t)|$ on the relevant interval. For trig/exp functions, this is often simply the maximum value of the function on the interval.
  3. Plug into the formula.

Worked Examples

Example 1Geometric Series Sum

Find the sum of $\displaystyle\sum_{n=1}^\infty \frac{3}{2^n}$.

1
Rewrite: $\displaystyle\sum_{n=1}^\infty 3\cdot\left(\frac{1}{2}\right)^n = 3\sum_{n=1}^\infty\left(\frac{1}{2}\right)^n = 3\cdot\frac{1/2}{1-1/2} = 3\cdot 1 = \boxed{3}$
Example 2Ratio Test

Determine convergence of $\displaystyle\sum_{n=1}^\infty \frac{n!}{3^n}$.

1
$\left|\dfrac{a_{n+1}}{a_n}\right| = \dfrac{(n+1)!/3^{n+1}}{n!/3^n} = \dfrac{n+1}{3} \to \infty > 1$.
2
By Ratio Test, the series diverges.
Example 3Interval of Convergence

Find the interval of convergence of $\displaystyle\sum_{n=1}^\infty \frac{(-1)^n x^n}{n}$.

1
Ratio test: $\lim\left|\dfrac{x^{n+1}/(n+1)}{x^n/n}\right| = |x|\cdot\dfrac{n}{n+1} \to |x|$. Converges when $|x| < 1$, i.e., $-1 < x < 1$.
2
Check endpoints: $x=1$: $\sum \dfrac{(-1)^n}{n}$ — alternating harmonic series, converges. $x=-1$: $\sum \dfrac{(-1)^n(-1)^n}{n} = \sum \dfrac{1}{n}$ — harmonic series, diverges.
3
Interval of convergence: $\boxed{-1 < x \le 1}$
Example 4Maclaurin Series for $e^x$

Derive the Maclaurin series for $f(x) = e^x$ and use it to approximate $e^{0.1}$ to 4 decimal places.

1
$f^{(n)}(x) = e^x$ for all $n$. $f^{(n)}(0) = 1$. Series: $e^x = \displaystyle\sum_{n=0}^\infty\dfrac{x^n}{n!}$.
2
$e^{0.1} \approx 1 + 0.1 + \dfrac{(0.1)^2}{2} + \dfrac{(0.1)^3}{6} + \dfrac{(0.1)^4}{24} = 1 + 0.1 + 0.005 + 0.0001\overline{6} + 0.0000041\overline{6} \approx \boxed{1.1052}$
Example 5Taylor Polynomial for $\cos x$

Write the 4th-degree Maclaurin polynomial for $\cos x$ and use it to estimate $\cos(0.2)$.

1
$T_4(x) = 1 - \dfrac{x^2}{2!} + \dfrac{x^4}{4!} = 1 - \dfrac{x^2}{2} + \dfrac{x^4}{24}$
2
$T_4(0.2) = 1 - \dfrac{0.04}{2} + \dfrac{0.0016}{24} = 1 - 0.02 + 0.0000\overline{6} \approx \boxed{0.9800}$. (Actual: $\cos 0.2 \approx 0.9801$)
Example 6Taylor Series by Substitution

Find the Maclaurin series for $f(x) = e^{-x^2}$.

1
Replace $x$ with $-x^2$ in $e^x = \sum x^n/n!$: $$e^{-x^2} = \sum_{n=0}^\infty \frac{(-x^2)^n}{n!} = \sum_{n=0}^\infty \frac{(-1)^n x^{2n}}{n!} = \boxed{1 - x^2 + \frac{x^4}{2} - \frac{x^6}{6} + \cdots}$$
Example 7Lagrange Error Bound

Use the 3rd-degree Maclaurin polynomial for $\sin x$ to approximate $\sin(0.3)$ and bound the error.

1
$T_3(x) = x - \dfrac{x^3}{6}$. So $T_3(0.3) = 0.3 - \dfrac{0.027}{6} = 0.3 - 0.0045 = 0.2955$.
2
Next term: $n+1 = 4$, so $f^{(4)}(x) = \sin x$. Max $|f^{(4)}(t)|$ on $[0, 0.3]$: $M = \sin(0.3) < 1$. Use $M=1$ (safe upper bound).
3
$|R_3(0.3)| \le \dfrac{1}{4!}(0.3)^4 = \dfrac{0.0081}{24} = 0.0003375 < \boxed{0.00034}$. Error is less than 0.034%.
Example 8Series from Integration

Use the series for $\dfrac{1}{1-x}$ to find the series for $\ln(1+x)$.

1
$\dfrac{1}{1+x} = \dfrac{1}{1-(-x)} = \sum_{n=0}^\infty (-x)^n = \sum_{n=0}^\infty (-1)^n x^n$ for $|x|<1$.
2
Integrate: $\displaystyle\int_0^x \frac{dt}{1+t} = \ln(1+x)$. So: $$\ln(1+x) = \int_0^x \sum_{n=0}^\infty(-1)^n t^n\,dt = \sum_{n=0}^\infty(-1)^n\frac{x^{n+1}}{n+1} = \boxed{x - \frac{x^2}{2}+\frac{x^3}{3}-\cdots}$$
