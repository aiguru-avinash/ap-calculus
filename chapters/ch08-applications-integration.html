8.1 Average Value of a Function

📐 Average Value
The average value of $f$ on $[a,b]$ is: $$f_{\text{avg}} = \frac{1}{b-a}\int_a^b f(x)\,dx$$
✅ Mean Value Theorem for Integrals
If $f$ is continuous on $[a,b]$, there exists $c \in (a,b)$ such that $f(c) = f_{\text{avg}}$. That is, $f$ attains its average value at some point.

8.2 Area Between Curves

📐 Area Between Curves
If $f(x) \ge g(x)$ on $[a,b]$: $$A = \int_a^b [f(x) - g(x)]\,dx$$ If the curves cross, split the interval at intersection points and take the absolute value of each piece.

Figure 8.1 — Area between $f(x)$ (upper) and $g(x)$ (lower) from $x=a$ to $x=b$.

📌 Integrating with Respect to $y$
Sometimes it's easier to integrate horizontally: $A = \displaystyle\int_c^d [R(y) - L(y)]\,dy$ where $R(y)$ is the right boundary and $L(y)$ is the left boundary.

8.3 Volumes — Disk/Washer Method

📐 Disk Method (rotating about $x$-axis)
When $f(x) \ge 0$: $$V = \pi \int_a^b [f(x)]^2\,dx$$ Each cross-section is a disk of radius $f(x)$.
📐 Washer Method (gap between two curves)
When rotating the region between $f(x) \ge g(x) \ge 0$ about the $x$-axis: $$V = \pi \int_a^b \left([f(x)]^2 - [g(x)]^2\right)dx$$ Outer radius $R = f(x)$, inner radius $r = g(x)$.

Figure 8.2 — Disk method. Rotating $f(x)$ about the $x$-axis generates a solid; each cross-section is a disk of radius $f(x)$.

8.4 Volumes — Shell Method BC

📐 Shell Method (rotating about $y$-axis)
$$V = 2\pi\int_a^b x\,f(x)\,dx \quad (f(x) \ge 0, \; 0 \le a < b)$$ Each "shell" has radius $x$, height $f(x)$, and thickness $dx$. Shell circumference $\times$ height $\times$ thickness: $2\pi x \cdot f(x) \cdot dx$.
📌 When to Use Each Method
  • Disk/Washer: when integrating along the axis of rotation (perpendicular slices).
  • Shell: when integrating parallel to the axis of rotation — avoids solving for the inverse function.

8.5 Arc Length BC

📐 Arc Length Formula
If $f'$ is continuous on $[a,b]$, the arc length of $y = f(x)$ from $a$ to $b$ is: $$L = \int_a^b \sqrt{1 + [f'(x)]^2}\,dx$$

Worked Examples

Example 1Average Value

Find the average value of $f(x) = \sin x$ on $[0, \pi]$.

1
$f_{\text{avg}} = \dfrac{1}{\pi - 0}\displaystyle\int_0^\pi \sin x\,dx = \dfrac{1}{\pi}\left[-\cos x\right]_0^\pi$
2
$= \dfrac{1}{\pi}[-\cos\pi - (-\cos 0)] = \dfrac{1}{\pi}[1 + 1] = \boxed{\dfrac{2}{\pi}}$
Example 2Area Between Curves

Find the area of the region bounded by $y = x^2$ and $y = 2x$.

1
Intersections: $x^2 = 2x \Rightarrow x(x-2) = 0 \Rightarrow x = 0, 2$. On $[0,2]$: $2x \ge x^2$.
2
$A = \displaystyle\int_0^2(2x - x^2)\,dx = \left[x^2 - \frac{x^3}{3}\right]_0^2 = (4 - \frac{8}{3}) - 0 = \frac{12-8}{3} = \boxed{\dfrac{4}{3}}$
Example 3Area — Three-Curve Region

Find the area enclosed by $y = x^2 - 4$, $y = x + 2$, from $x = -2$ to $x = 3$. The curves intersect at $x = -2$ and $x = 3$.

1
Intersections: $x^2-4 = x+2 \Rightarrow x^2-x-6=0 \Rightarrow (x-3)(x+2)=0 \Rightarrow x=-2,3$.
2
On $[-2,3]$: $x+2 \ge x^2-4$ (test $x=0$: $2 \ge -4$ ✓).
3
$A = \displaystyle\int_{-2}^3[(x+2)-(x^2-4)]\,dx = \int_{-2}^3(-x^2+x+6)\,dx$ $= \left[-\dfrac{x^3}{3}+\dfrac{x^2}{2}+6x\right]_{-2}^3$ $= \left(-9+\dfrac{9}{2}+18\right) - \left(\dfrac{8}{3}+2-12\right)$ $= \dfrac{27}{2} - (-\dfrac{22}{3}) = \dfrac{27}{2}+\dfrac{22}{3} = \dfrac{81+44}{6} = \boxed{\dfrac{125}{6}}$
Example 4Volume — Disk Method

Find the volume of the solid formed by rotating $y = \sqrt{x}$ about the $x$-axis on $[0, 4]$.

1
$V = \pi\displaystyle\int_0^4 (\sqrt{x})^2\,dx = \pi\int_0^4 x\,dx$
2
$= \pi\left[\dfrac{x^2}{2}\right]_0^4 = \pi \cdot 8 = \boxed{8\pi}$
Example 5Volume — Washer Method

Find the volume of the solid obtained by rotating the region between $y = x^2$ and $y = x$ (on $[0,1]$) about the $x$-axis.

1
On $[0,1]$: $x \ge x^2$. Outer radius $R = x$, inner radius $r = x^2$.
2
$V = \pi\displaystyle\int_0^1 (x^2 - x^4)\,dx = \pi\left[\dfrac{x^3}{3} - \dfrac{x^5}{5}\right]_0^1 = \pi\left(\dfrac{1}{3}-\dfrac{1}{5}\right) = \pi\cdot\dfrac{2}{15} = \boxed{\dfrac{2\pi}{15}}$
Example 6Volume — Shell Method (BC)

Use the shell method to find the volume generated by rotating $y = x^2$ on $[0,2]$ about the $y$-axis.

1
$V = 2\pi\displaystyle\int_0^2 x \cdot x^2\,dx = 2\pi\int_0^2 x^3\,dx$
2
$= 2\pi\left[\dfrac{x^4}{4}\right]_0^2 = 2\pi\cdot 4 = \boxed{8\pi}$
Example 7Arc Length (BC)

Find the arc length of $y = \dfrac{x^2}{2} - \dfrac{\ln x}{4}$ from $x=1$ to $x=e$.

1
$f'(x) = x - \dfrac{1}{4x}$. Then $[f'(x)]^2 = x^2 - \dfrac{1}{2} + \dfrac{1}{16x^2}$.
2
$1 + [f'(x)]^2 = x^2 + \dfrac{1}{2} + \dfrac{1}{16x^2} = \left(x + \dfrac{1}{4x}\right)^2$. So $\sqrt{1+[f']^2} = x + \dfrac{1}{4x}$.
3
$L = \displaystyle\int_1^e\!\left(x + \frac{1}{4x}\right)dx = \left[\frac{x^2}{2} + \frac{\ln x}{4}\right]_1^e = \left(\frac{e^2}{2}+\frac{1}{4}\right) - \frac{1}{2} = \boxed{\frac{e^2}{2} - \frac{1}{4}}$
