A $\dfrac{y}{x}$
B $-\dfrac{y}{x}$
C $\dfrac{x}{y}$

Find $\dfrac{dy}{dx}$ if $\sin(xy) = x$.
A $\dfrac{1-y\cos(xy)}{x\cos(xy)}$
B $\dfrac{\cos(xy)-1}{x}$
C $\dfrac{1}{\cos(xy)}$
D $\dfrac{y\cos(xy)-1}{x\cos(xy)}$
Differentiate: $\cos(xy)(y+x\dfrac{dy}{dx})=1$. Solve: $x\cos(xy)\dfrac{dy}{dx}=1-y\cos(xy)$, so $\dfrac{dy}{dx}=\dfrac{1-y\cos(xy)}{x\cos(xy)}$.

B $3y^2+3$

A $5$
B $3$
C $\dfrac{5}{3}$
D $15$
Chain rule: $g'(x) = f'(3x+1)\cdot 3$. At $x=1$: $g'(1) = f'(4)\cdot 3 = 5\cdot 3 = 15$.
