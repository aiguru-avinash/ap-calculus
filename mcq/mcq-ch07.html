The solution to $\dfrac{dy}{dx} = 2y$ with $y(0)=3$ is
A $y=2e^{3x}$
B $y=3e^{2x}$
C $y=e^{6x}$
D $y=3e^x$
Separate: $\int\dfrac{dy}{y}=\int 2\,dx\Rightarrow\ln|y|=2x+C$. With $y(0)=3$: $C=\ln 3$. So $y=3e^{2x}$.
2
A population grows at rate $\dfrac{dP}{dt}=0.04P$. If $P(0)=500$, then $P(25)=$
A 1000
B $500e$
C $500e^1$
D $500e^{0.04}$
$P(t)=500e^{0.04t}$. $P(25)=500e^{0.04\cdot25}=500e^1=500e$. (Options B and C are the same; $500e$=C.)
3
The slope field for $\dfrac{dy}{dx} = x$ has segments with slope 0 along
A the $y$-axis ($x=0$)
B the $x$-axis ($y=0$)
C the line $y=x$
D everywhere
$dy/dx=x=0$ when $x=0$ — the $y$-axis. At any point on the $y$-axis the slope segment is horizontal.
4
Euler's method uses the update formula
A $y_{n+1} = y_n + h\cdot f(x_n,y_n)^2$
B $y_{n+1} = y_n - hf(x_n,y_n)$
C $y_{n+1} = x_n + hf(x_n,y_n)$
D $y_{n+1} = y_n + hf(x_n,y_n)$
Euler's method: $y_{n+1}=y_n+h\cdot f(x_n,y_n)$ where $h$ is the step size and $f(x,y)=dy/dx$.
5
Using Euler's method with $h=0.1$: $\dfrac{dy}{dx}=x+y$, $y(0)=1$. Estimate $y(0.1)$.
A 1.0
B 1.1
C 1.2
D 1.01
$y_1=y_0+h\cdot f(x_0,y_0)=1+0.1(0+1)=1+0.1=1.1$.
6
The half-life of a substance decaying as $y=y_0 e^{-kt}$ ($k>0$) is
A $\ln 2$
B $1/k$
C $\dfrac{\ln 2}{k}$
D $k\ln 2$
Set $y=y_0/2$: $e^{-kt_{1/2}}=1/2\Rightarrow kt_{1/2}=\ln 2\Rightarrow t_{1/2}=\dfrac{\ln 2}{k}$.
7
The logistic DE $\dfrac{dP}{dt}=kP\!\left(1-\dfrac{P}{M}\right)$ has maximum rate of change when
A $P = M/2$
B $P = M$
C $P = 0$
D $P = 2M$
$f(P)=P(1-P/M)$ is maximized by $f'(P)=1-2P/M=0\Rightarrow P=M/2$.
8
The carrying capacity of the logistic model is
A 0
B $k$
C $k/M$
D $M$
In $dP/dt=kP(1-P/M)$, $P\to M$ as $t\to\infty$. $M$ is the carrying capacity (maximum sustainable population).
9
The general solution of $\dfrac{dy}{dx} = \dfrac{x}{y}$ is
A $y = x^2/2 + C$
B $y = x + C$
C $y^2 = x^2 + C$
D $y^2 = x + C$
Separate: $y\,dy=x\,dx\Rightarrow\dfrac{y^2}{2}=\dfrac{x^2}{2}+K\Rightarrow y^2=x^2+C$ (absorbing factor of 2).
10
A sample of 100g decays with $k=0.02$/year. When does it reach 50g?
A 25 years
B $\approx$ 34.7 years
C 50 years
D 100 years
$t_{1/2}=\dfrac{\ln 2}{0.02}=\dfrac{0.6931}{0.02}\approx34.7$ years.
11
What does the direction field (slope field) for a DE visually represent?
A Short line segments showing slopes of solution curves
B The graph of a single solution
C The second derivative at each point
D The antiderivative surface
A slope field displays short line segments at grid points $(x,y)$, each with slope $dy/dx=f(x,y)$. Together they show the family of solution curves.
12
The particular solution to $\dfrac{dy}{dx}=3x^2$, $y(1)=4$ is
A $y=x^3$
B $y=x^3+4$
C $y=3x^3+C$
D $y=x^3+3$
$y=\int 3x^2\,dx=x^3+C$. $y(1)=1+C=4\Rightarrow C=3$. So $y=x^3+3$.
13
For the logistic model, as $P\to M$, the growth rate $dP/dt$
A approaches $kM$
B increases without bound
C approaches 0
D becomes negative
$dP/dt=kP(1-P/M)\to kM(1-1)=0$ as $P\to M$. The population growth slows to zero.
14
If $\dfrac{dT}{dt}=-k(T-70)$ (Newton's law of cooling) and $T(0)=170$, $k=0.1$, then $T(t)=$
A $70e^{-0.1t}+100$
B $100e^{-0.1t}+70$
C $170e^{-0.1t}$
D $100e^{0.1t}+70$
Let $u=T-70$: $du/dt=-ku\Rightarrow u=Ce^{-kt}$. $u(0)=100\Rightarrow C=100$. $T=100e^{-0.1t}+70$.
15
$\dfrac{dy}{dx} = \dfrac{y^2}{x}$ is separable. Its general solution is
A $-1/y = \ln|x|+C$
B $y = x^2/2+C$
C $y^2 = \ln|x|+C$
D $y = Ce^{\ln x}$
$\int y^{-2}dy=\int x^{-1}dx\Rightarrow-1/y=\ln|x|+C$.
16
Using Euler's method with $h=0.1$, $dy/dx=y$, $y(0)=1$: $y(0.2)\approx$
A 1.2
B 1.1
C 1.22
D 1.21
$y_1=1+0.1(1)=1.1$; $y_2=1.1+0.1(1.1)=1.1+0.11=1.21$.
17
An exponential model $y=y_0 e^{kt}$ has $k<0$ if the quantity is
A growing
B constant
C decaying
D oscillating
$k<0\Rightarrow e^{kt}\to 0$ as $t\to\infty$: exponential decay. $k>0$ gives growth.
18
The order of the DE $\dfrac{d^2y}{dx^2}+3\dfrac{dy}{dx}-y=0$ is
A 1st order
B 2nd order
C 3rd order
D 0th order
The order equals the highest derivative present. Here $d^2y/dx^2$ is a 2nd derivative → 2nd order.
19
A solution curve through $(0,1)$ for $dy/dx=xy$ passes through which region when $x>0$?
A increasing (slopes are positive)
B decreasing (slopes are negative)
C concave down
D constant
For $x>0$ and $y>0$ (near $(0,1)$): $dy/dx=xy>0$, so the solution is increasing.
20
The equilibria (constant solutions) of $\dfrac{dP}{dt}=0.1P(1-P/500)$ are
A $P=500$ only
B $P=250$ only
C $P=0.1$ only
D $P=0$ and $P=500$
$dP/dt=0$ when $P=0$ or $1-P/500=0\Rightarrow P=500$. Both are equilibrium solutions.
