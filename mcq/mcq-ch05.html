The Mean Value Theorem guarantees a $c \in (a,b)$ such that $f'(c) = \dfrac{f(b)-f(a)}{b-a}$ provided $f$ is
A differentiable on $[a,b]$
B continuous on $[a,b]$ and differentiable on $(a,b)$
C increasing on $[a,b]$
D continuous on $(a,b)$
MVT requires: continuous on $[a,b]$ AND differentiable on $(a,b)$.
2
The absolute maximum of $f(x) = -x^2 + 4x$ on $[0, 5]$ is
A 0
B 3
C 4
D 5
$f'(x)=-2x+4=0\Rightarrow x=2$. Check: $f(0)=0$, $f(2)=4$, $f(5)=-5$. Max is $4$.
3
If $f'(x) > 0$ on $(a,b)$ and $f'(x) < 0$ on $(b,c)$, then $f$ has a local
A maximum at $x=b$
B minimum at $x=b$
C inflection point at $x=b$
D neither max nor min at $x=b$
First Derivative Test: $f'$ changes from $+$ to $-$ at $b$ → local maximum.
4
$f(x) = x^3 - 3x$ has inflection points at
A $x = \pm 1$
B $x = 1$ only
C $x = -1$ only
D $x = 0$
$f''(x)=6x=0\Rightarrow x=0$. $f''$ changes sign at $x=0$ (negative left, positive right), confirming an inflection point.
5
If $f''(c) > 0$, then $f$ is _____ at $x=c$.
A decreasing
B concave up
C concave down
D at a local max
$f''>0$ means concave up (bowl-shaped opening upward).
6
For $f(x) = x^3$, at $x=0$: $f'(0)=0$ and $f''(0)=0$. The Second Derivative Test is
A shows a local min
B shows a local max
C inconclusive
D shows an inflection point
When $f''(c)=0$, the Second Derivative Test is inconclusive. Use First Derivative Test: $f'$ doesn't change sign at 0, confirming an inflection point.
7
The critical numbers of $f(x) = x^4 - 4x^3$ are
A $x=0$ and $x=3$
B $x=3$ only
C $x=0, 1, 3$
D $x=0$ only
$f'(x)=4x^3-12x^2=4x^2(x-3)=0\Rightarrow x=0$ or $x=3$.
8
A farmer has 200 m of fence to enclose a rectangular field against a barn (one side free). The maximum area is
A 2500 m²
B 4000 m²
C 10000 m²
D 5000 m²
Let $x$ = width (both sides). Constraint: $2x+L=200$, so $L=200-2x$. $A=xL=x(200-2x)$. $A'=200-4x=0\Rightarrow x=50$. $A_{max}=50(100)=5000$ m².
9
Rolle's Theorem requires
A $f(a)=0$ and $f(b)=0$
B continuous on $[a,b]$, differentiable on $(a,b)$, and $f(a)=f(b)$
C $f$ is increasing on $[a,b]$
D differentiable on $[a,b]$ only
Rolle's: continuous on $[a,b]$, differentiable on $(a,b)$, and $f(a)=f(b)$ (equal, not necessarily zero). Then $\exists c\in(a,b)$ with $f'(c)=0$.
10
The absolute minimum of $f(x) = 2x^3 - 3x^2$ on $[-1, 2]$ is
A $4$
B $-1$
C $-5$
D $0$
$f'=6x^2-6x=6x(x-1)=0\Rightarrow x=0,1$. $f(-1)=-2-3=-5$; $f(0)=0$; $f(1)=-1$; $f(2)=4$. Min = $-5$.
11
If $f'(x) > 0$ for all $x$ on $(a,b)$, then $f$ is
A increasing on $(a,b)$
B concave up on $(a,b)$
C at a local min on $(a,b)$
D decreasing on $(a,b)$
$f'>0\Rightarrow f$ is strictly increasing. Concavity is determined by $f''$, not $f'$.
12
For $f(x) = xe^{-x}$, the local maximum value is
A $0$
B $e$
C $e^{-1}$
D $e^{-1}$
$f'(x)=(1-x)e^{-x}=0\Rightarrow x=1$. $f''(x)=(x-2)e^{-x}$; $f''(1)=-e^{-1}<0$: local max. $f(1)=e^{-1}$.
13
$f(x) = x^3 - 3x + 2$ is decreasing on the interval
A $(-\infty, -1)$
B $(1, \infty)$
C $(-1, 1)$
D $(-\infty, 0)$
$f'=3x^2-3=3(x^2-1)=3(x-1)(x+1)<0$ on $(-1,1)$.
14
At a critical point where $f'(c)=0$ and $f''(c) > 0$, the function has a
A local maximum
B local minimum
C inflection point
D saddle point
Second Derivative Test: $f'(c)=0$ and $f''(c)>0\Rightarrow$ local minimum (concave up at that point).
15
The Extreme Value Theorem guarantees absolute extrema when $f$ is
A continuous on a closed interval $[a,b]$
B differentiable on an open interval $(a,b)$
C defined on all of $\mathbb{R}$
D monotone on $[a,b]$
EVT: if $f$ is continuous on $[a,b]$, then $f$ attains both an absolute max and min on $[a,b]$.
16
A function is concave down on an interval when
A $f' > 0$
B $f'' > 0$
C $f' < 0$
D $f'' < 0$
Concave down $\Leftrightarrow$ $f'' < 0$ (the graph curves downward, like an inverted bowl).
17
Which function has a horizontal asymptote at $y=0$?
A $f(x)=e^x$
B $f(x)=\ln x$
C $f(x)=e^{-x}$
D $f(x)=x^2$
$\lim_{x\to\infty}e^{-x}=0$, so $y=0$ is a horizontal asymptote of $e^{-x}$.
18
To minimize a product $P = xy$ subject to $x + y = 20$, the minimum occurs at
A $x=10, y=10$
B boundary values
C $x=5, y=15$
D $x=y=0$
$P=x(20-x)=-x^2+20x$. This has a maximum at $x=10$. There is no minimum on an open domain — minimum occurs at boundaries.
19
The value of $c$ guaranteed by MVT for $f(x) = x^2$ on $[1, 3]$ is
A $2$
B $\sqrt{3}$
C $1$
D $3$
$\dfrac{f(3)-f(1)}{3-1}=\dfrac{9-1}{2}=4$. $f'(c)=2c=4\Rightarrow c=2\in(1,3)$. ✓
20
A box with no top is made from a square sheet of cardboard 12 cm per side by cutting equal squares from corners and folding up sides. The side length of the cut squares that maximizes volume is
A 1 cm
B 3 cm
C 4 cm
D 2 cm
$V=x(12-2x)^2$. $V'=(12-2x)^2+x\cdot2(12-2x)(-2)=(12-2x)(12-6x)=0$. So $x=6$ (invalid) or $x=2$. Max volume at $x=2$ cm.
