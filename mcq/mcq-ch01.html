$\displaystyle\lim_{x \to 2} \frac{x^2 - 4}{x - 2}$ equals
A 0
B 4
C 2
D Does not exist
Factor: $(x^2-4)/(x-2) = (x-2)(x+2)/(x-2) = x+2$. At $x=2$: $2+2=4$.
2
$\displaystyle\lim_{x \to 0} \frac{\sin(5x)}{x}$ equals
A 0
B 1
C 5
D $1/5$
$\dfrac{\sin(5x)}{x} = 5\cdot\dfrac{\sin(5x)}{5x} \to 5\cdot 1 = 5$ as $x\to 0$.
3
$\displaystyle\lim_{x \to \infty} \frac{3x^2 + 5}{x^2 - 1}$ equals
A 3
B 5
C $\infty$
D 0
Divide by $x^2$: $(3+5/x^2)/(1-1/x^2) \to 3/1 = 3$.
4
$\displaystyle\lim_{x \to 0} \frac{1-\cos x}{x}$ equals
A 1
B $-1$
C $1/2$
D 0
Standard limit: $\lim_{x\to 0}\dfrac{1-\cos x}{x} = 0$.

Which of the following is a necessary condition for $\displaystyle\lim_{x \to a} f(x)$ to exist?
A $f(a)$ must be defined
B The left and right one-sided limits must both exist and be equal
C $f$ must be continuous at $a$
D $f'(a)$ must exist
By definition, the two-sided limit exists iff both one-sided limits exist and are equal. $f(a)$ need not be defined.
6
$f(x) = \dfrac{x^2 - 9}{x-3}$ has what type of discontinuity at $x=3$?
A Jump
B Infinite
C Removable
D No discontinuity
$(x^2-9)/(x-3) = x+3$ for $x\ne 3$. Limit $= 6$ exists but $f(3)$ undefined → removable.
7
If $f(x) = \begin{cases} x+1 & x < 2\\ 3 & x=2\\ 2x-1 & x>2 \end{cases}$, then $\displaystyle\lim_{x\to 2}f(x)$ equals
A 3
B Does not exist
C 2
D 1
Left: $\lim_{x\to 2^-}(x+1) = 3$. Right: $\lim_{x\to 2^+}(2x-1)=3$. Both equal 3, so limit $= 3$. ($f(2)=3$ too — this function is actually continuous!)
8
$\displaystyle\lim_{x \to 4} \frac{\sqrt{x} - 2}{x - 4}$ equals
A 0
B Does not exist
C 2
D $\dfrac{1}{4}$
Multiply by conjugate: $\dfrac{(\sqrt{x}-2)(\sqrt{x}+2)}{(x-4)(\sqrt{x}+2)} = \dfrac{x-4}{(x-4)(\sqrt{x}+2)} = \dfrac{1}{\sqrt{x}+2}\to\dfrac{1}{4}$.
9
Which function is continuous at $x=0$?
A $f(x) = \dfrac{1}{x}$
B $g(x) = x\sin\!\left(\dfrac{1}{x}\right)$ with $g(0)=0$
C $h(x) = \dfrac{|x|}{x}$
D $k(x) = \dfrac{\sin x}{x}$ with $k(0)=0$
$g(x)=x\sin(1/x)$: squeeze theorem gives $\lim_{x\to 0} g(x)=0=g(0)$ ✓. (D is wrong because $k(0)$ should be 1 for continuity, not 0.)
10
For $f(x) = \dfrac{2x^3 - x}{4x^3 + 1}$, the horizontal asymptote is
A $y = 0$
B $y = -1$
C $y = \dfrac{1}{2}$
D $y = 2$
Equal degrees: ratio of leading coefficients $= 2/4 = 1/2$.
11
The Intermediate Value Theorem guarantees that $f(x) = x^3 - 3x + 1$ has a root in
A $(1, 2)$
B $(-3, -2)$
C $(3, 4)$
D $(2, 3)$
$f(1)=1-3+1=-1<0$ and $f(2)=8-6+1=3>0$. Sign change → root in $(1,2)$ by IVT.
12
$\displaystyle\lim_{x\to 0^+} \ln x$ equals
A 0
B 1
C $+\infty$
D $-\infty$
As $x\to 0^+$, $\ln x\to -\infty$ (vertical asymptote at $x=0$).
13
If $-x^2 \le f(x) \le x^2$ for all $x$, then $\displaystyle\lim_{x\to 0}f(x)$ equals
A $-1$
B 0
C 1
D Does not exist
Squeeze Theorem: $\lim_{x\to 0}(-x^2) = \lim_{x\to 0}(x^2) = 0$, so $\lim f(x) = 0$.
14
At which value of $x$ does $f(x) = \dfrac{x}{x^2-4}$ have a vertical asymptote?
A $x=0$ only
B $x=4$ only
C $x=2$ and $x=-2$
D $x=\pm 4$
$x^2-4=(x-2)(x+2)=0$ at $x=\pm 2$. Numerator $\ne 0$ there, so vertical asymptotes at $x=2$ and $x=-2$.
15
Which of the following statements about continuity is FALSE?
A If $f$ is differentiable at $a$, then $f$ need not be continuous at $a$
B Polynomials are continuous everywhere
C If $f$ and $g$ are continuous at $a$, then $f+g$ is continuous at $a$
D A function continuous on $[a,b]$ attains its maximum and minimum on $[a,b]$
A is FALSE: differentiability IMPLIES continuity. If $f$ is differentiable at $a$, it MUST be continuous at $a$.
16
$\displaystyle\lim_{x\to\infty}\frac{\sqrt{4x^2+3}}{x+1}$ equals
A $\infty$
B 2
C $\sqrt{4}$
D 4
Divide by $x$ (for $x>0$): $\dfrac{\sqrt{4+3/x^2}}{1+1/x}\to\dfrac{\sqrt{4}}{1}=2$.
17
For $f(x) = \begin{cases}kx & x<2\\ x^2-1 & x\ge 2\end{cases}$ to be continuous at $x=2$, the value of $k$ must be
A 1
B 2
C $\dfrac{3}{2}$
D 3
From the right: $f(2) = 2^2-1=3$. From the left: $\lim_{x\to 2^-}(kx) = 2k$. For continuity: $2k=3 \Rightarrow k=\dfrac{3}{2}$.
18
$\displaystyle\lim_{x\to 0}\frac{\tan(2x)}{3x}$ equals
A $\dfrac{2}{3}$
B $\dfrac{3}{2}$
C 0
D 1
$\dfrac{\tan(2x)}{3x} = \dfrac{2}{3}\cdot\dfrac{\tan(2x)}{2x}\to\dfrac{2}{3}\cdot 1=\dfrac{2}{3}$. (Since $\lim_{\theta\to 0}\tan\theta/\theta=1$.)
19
Which statement correctly describes $f(x) = \sin(1/x)$ at $x=0$?
A $\displaystyle\lim_{x\to 0}f(x) = 0$
B $f$ has a jump discontinuity at $x=0$
C $f$ has a removable discontinuity at $x=0$
D $\displaystyle\lim_{x\to 0}f(x)$ does not exist
$\sin(1/x)$ oscillates infinitely between $-1$ and $1$ as $x\to 0$, so the limit does not exist (oscillating, not a jump discontinuity in the usual sense).
20
If $\displaystyle\lim_{x\to a}f(x) = 5$ and $\displaystyle\lim_{x\to a}g(x) = -2$, then $\displaystyle\lim_{x\to a}[3f(x) - g(x)^2]$ equals
A 11
B 11
C 19
D $-11$
$3(5) - (-2)^2 = 15 - 4 = 11$. By limit laws.
