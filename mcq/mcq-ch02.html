If $f(x) = 4x^5 - 3x^2 + 7$, then $f'(x) =$
A $20x^4 - 6x + 7$
B $20x^4 - 6x$
C $4x^4 - 3x$
D $20x^5 - 6x$
Power rule: $5\cdot 4x^4 - 2\cdot 3x + 0 = 20x^4 - 6x$. The constant 7 differentiates to 0.

$\dfrac{d}{dx}\!\left[\sqrt[3]{x^2}\right] =$
A $\dfrac{3}{2}x^{1/2}$
B $\dfrac{2}{3}x$

D $\dfrac{1}{3}x^{-2/3}$
$x^{2/3}$: power rule gives $\dfrac{2}{3}x^{2/3-1} = \dfrac{2}{3}x^{-1/3}$.

Using the limit definition, which expression equals $f'(x)$ for $f(x) = x^2$?
A $\lim_{h\to 0}\dfrac{(x+h)^2 - x^2}{h}$
B $\lim_{h\to 0}\dfrac{(x+h)^2}{h}$
C $\lim_{h\to\infty}\dfrac{(x+h)^2 - x^2}{h}$
D $\dfrac{(x+h)^2 - x^2}{h}$
By definition: $f'(x) = \lim_{h\to 0}\dfrac{f(x+h)-f(x)}{h}$.
4
$\dfrac{d}{dx}[x^2\cos x] =$
A $-2x\sin x$
B $2x\cos x + x^2\sin x$
C $2x\cos x$
D $2x\cos x - x^2\sin x$
Product rule: $(x^2)'\cos x + x^2(\cos x)' = 2x\cos x + x^2(-\sin x) = 2x\cos x - x^2\sin x$.
5
$\dfrac{d}{dx}\!\left[\dfrac{e^x}{x}\right] =$
A $e^x$
B $\dfrac{xe^x - e^x}{x^2}$
C $\dfrac{e^x}{x^2}$
D $\dfrac{e^x(x+1)}{x^2}$
Quotient rule: $\dfrac{e^x\cdot x - e^x\cdot 1}{x^2} = \dfrac{e^x(x-1)}{x^2}$. This equals $\dfrac{xe^x-e^x}{x^2}$.

If $f(x) = \tan x$, then $f'(\pi/4) =$
A $\sqrt{2}$
B 1
C 2
D $\dfrac{1}{2}$
$f'(x) = \sec^2 x$. $\sec(\pi/4) = \sqrt{2}$, so $\sec^2(\pi/4) = 2$.

The slope of the tangent to $y = \ln x$ at $x = e$ is
A $1/e$
B $e$
C 1
D $\ln e$
$\dfrac{d}{dx}[\ln x] = \dfrac{1}{x}$. At $x=e$: slope $= \dfrac{1}{e}$.

If $g(x) = 3^x$, then $g'(x) =$
A $x \cdot 3^{x-1}$
B $3^x$
C $3^x/\ln 3$
D $3^x \ln 3$
For $a^x$: $\dfrac{d}{dx}[a^x] = a^x\ln a$. So $g'(x) = 3^x\ln 3$.
9
The equation of the tangent line to $f(x) = x^3$ at $(2, 8)$ is
A $y = 3x - 2$
B $y = 12x - 16$
C $y = 6x - 4$
D $y = 12x - 8$
$f'(x)=3x^2$, $f'(2)=12$. Tangent: $y-8=12(x-2) \Rightarrow y=12x-16$.
10
$\dfrac{d}{dx}[\sec x] =$
A $-\csc x\cot x$
B $\tan x\sec x$
C $\sec x\tan x$
D $\csc^2 x$
Standard result: $\dfrac{d}{dx}[\sec x] = \sec x\tan x$. (Derived using quotient rule on $1/\cos x$.)
11
Which function is NOT differentiable at $x=0$?
A $f(x) = |x|$
B $g(x) = x^2$
C $h(x) = \sin x$
D $k(x) = e^x$
$|x|$ has a corner at $x=0$: left derivative = $-1$, right derivative = $1$, so it is not differentiable there.

If $f(x) = \dfrac{x^2-1}{x+1}$ for $x\ne -1$, then $f'(0) =$
A $-1$
B 0
C 2
D 1
Simplify: $\dfrac{(x-1)(x+1)}{x+1} = x-1$ for $x\ne -1$. So $f'(x) = 1$, and $f'(0) = 1$.
13
$\dfrac{d}{dx}[x^{-5}] =$
A $5x^4$
B $-5x^4$
C $-5x^{-6}$
D $5x^{-6}$
Power rule: $(-5)x^{-5-1} = -5x^{-6}$.
14
If a particle's position is $s(t) = t^3 - 3t$, its velocity at $t=2$ is
A 2
B 9
C 5
D 6
$v(t) = s'(t) = 3t^2-3$. At $t=2$: $v(2) = 12-3 = 9$.
15
$\dfrac{d}{dx}[xe^x]$ evaluated at $x=1$ equals
A $2e$
B $e$
C $e^2$
D $e+1$
Product: $(xe^x)' = e^x + xe^x = e^x(1+x)$. At $x=1$: $e^1(2) = 2e$.
16
If $f'(x) = \cos x$, then $f(x) =$
A $-\sin x$
B $-\cos x + C$
C $\cos x + C$
D $\sin x + C$
Antiderivative of $\cos x$ is $\sin x + C$, since $\dfrac{d}{dx}[\sin x] = \cos x$.
17
The derivative of $f(x) = 5e^x - 3\ln x$ is
A $5e^x - 3x$
B $5e^x - 3\ln x$
C $5e^x - \dfrac{3}{x}$
D $5xe^{x-1} - \dfrac{3}{x}$
$\dfrac{d}{dx}[5e^x] = 5e^x$; $\dfrac{d}{dx}[3\ln x] = \dfrac{3}{x}$. So $f'(x) = 5e^x - \dfrac{3}{x}$.

Which of the following must be TRUE about a function $f$ if $f'(a) = 0$?
A $f$ has a local extremum at $x=a$
B $x=a$ is a critical number of $f$
C $f$ is increasing through $x=a$
D $f$ has an inflection point at $x=a$
If $f'(a)=0$, then $a$ is a critical number by definition. It need not be an extremum (e.g., $f(x)=x^3$ at $x=0$) or an inflection point.
19
$\dfrac{d}{dx}\!\left[\dfrac{\sin x}{\cos x}\right]$ simplifies to
A $\sec^2 x$
B $\csc^2 x$
C 1
D $-\csc^2 x$
$\dfrac{d}{dx}[\tan x] = \sec^2 x$. Alternatively, quotient rule: $\dfrac{\cos^2 x + \sin^2 x}{\cos^2 x} = \dfrac{1}{\cos^2 x} = \sec^2 x$.
20
If $h(x) = \dfrac{x^3 + 2x}{x}$ for $x\ne 0$, then $h'(1) =$
A 5
B 3
C 2
D 1
Simplify: $h(x) = x^2+2$. Then $h'(x)=2x$. $h'(1)=2$.
