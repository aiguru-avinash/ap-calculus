6.1 Antiderivatives & Indefinite Integrals

📐 Antiderivative
$F$ is an antiderivative of $f$ on an interval if $F'(x) = f(x)$ for all $x$ in that interval. The general antiderivative includes the constant $C$: $$\int f(x)\,dx = F(x) + C$$
✅ Basic Integration Rules
RuleFormula
Constant$\int k\,dx = kx + C$
Power ($n \ne -1$)$\int x^n\,dx = \dfrac{x^{n+1}}{n+1} + C$
$\int \frac{1}{x}\,dx$$\ln|x| + C$
$\int e^x\,dx$$e^x + C$
$\int a^x\,dx$$\dfrac{a^x}{\ln a} + C$
$\int \sin x\,dx$$-\cos x + C$
$\int \cos x\,dx$$\sin x + C$
$\int \sec^2 x\,dx$$\tan x + C$
$\int \csc^2 x\,dx$$-\cot x + C$
$\int \sec x\tan x\,dx$$\sec x + C$
$\int \csc x\cot x\,dx$$-\csc x + C$
$\int \frac{1}{\sqrt{1-x^2}}\,dx$$\arcsin x + C$
$\int \frac{1}{1+x^2}\,dx$$\arctan x + C$

6.2 Riemann Sums & The Definite Integral

A Riemann sum approximates the area under a curve by summing areas of rectangles.

📐 Riemann Sum
Partition $[a,b]$ into $n$ subintervals of width $\Delta x = \dfrac{b-a}{n}$. Choose sample points $x_i^*$ in each subinterval: $$\sum_{i=1}^{n} f(x_i^*)\,\Delta x$$ Types: Left ($x_i^* = $ left endpoint), Right ($x_i^* = $ right endpoint), Midpoint.
📐 Definite Integral
$$\int_a^b f(x)\,dx = \lim_{n\to\infty} \sum_{i=1}^{n} f(x_i^*)\,\Delta x$$ This equals the net signed area between the curve and the $x$-axis on $[a,b]$.
Figure 6.1 Riemann sums. Right-endpoint rectangles of width $\Delta x$ approximate the area; as $n\to\infty$ the approximation becomes exact.

6.3 Fundamental Theorem of Calculus

✅ FTC Part 1 — Derivative of an Integral
If $f$ is continuous on $[a,b]$ and $g(x) = \displaystyle\int_a^x f(t)\,dt$, then: $$g'(x) = f(x)$$ In general (with chain rule): $\dfrac{d}{dx}\!\left[\int_a^{u(x)} f(t)\,dt\right] = f(u(x)) \cdot u'(x)$
✅ FTC Part 2 — Evaluation Theorem
If $F$ is any antiderivative of $f$, then: $$\int_a^b f(x)\,dx = F(b) - F(a) \equiv \Big[F(x)\Big]_a^b$$
📝 Example — FTC Part 1 with Chain Rule
$\dfrac{d}{dx}\!\left[\displaystyle\int_1^{x^3} \sin t\,dt\right] = \sin(x^3) \cdot 3x^2$
Figure 6.2 Fundamental Theorem, Part 1. If $A(x)=\int_a^x f(t)\,dt$, nudging $x$ adds a thin strip of height $f(x)$, so $A'(x)=f(x)$.

6.4 Properties of Definite Integrals

PropertyFormula
Zero width$\displaystyle\int_a^a f\,dx = 0$
Reversal$\displaystyle\int_b^a f\,dx = -\displaystyle\int_a^b f\,dx$
Sum$\displaystyle\int_a^b (f+g)\,dx = \int_a^b f\,dx + \int_a^b g\,dx$
Constant multiple$\displaystyle\int_a^b cf\,dx = c\int_a^b f\,dx$
Additivity$\displaystyle\int_a^b f\,dx + \int_b^c f\,dx = \int_a^c f\,dx$
ComparisonIf $f \ge g$ on $[a,b]$: $\displaystyle\int_a^b f\,dx \ge \int_a^b g\,dx$

6.5 U-Substitution (Change of Variable)

📐 U-Substitution
Let $u = g(x)$, $du = g'(x)\,dx$. Then: $$\int f(g(x))\,g'(x)\,dx = \int f(u)\,du$$ For definite integrals, also change the bounds: if $x = a \Rightarrow u = g(a)$; $x = b \Rightarrow u = g(b)$.
📌 Choosing $u$
Pick $u$ to be the "inside" of a composition, especially if you see $u'$ (or a constant multiple of it) already in the integral.
📝 Quick Example
$\displaystyle\int 2x\cos(x^2)\,dx$: let $u = x^2$, $du = 2x\,dx$. $= \displaystyle\int \cos u\,du = \sin u + C = \sin(x^2) + C$.

6.6 Integration by Parts BC

✅ Integration by Parts Formula
$$\int u\,dv = uv - \int v\,du$$ Derived from the product rule: $(uv)' = u'v + uv'$.
📌 LIATE Guideline for Choosing $u$
Pick $u$ from the first matching category: Logarithmic, Inverse trig, Algebraic (polynomials), Trigonometric, Exponential. Then $dv$ = everything else.

6.7 Partial Fraction Decomposition BC

Used to integrate rational functions by decomposing them into simpler fractions.

📝 Example
$\displaystyle\int \frac{1}{x^2-1}\,dx = \int \frac{1}{(x-1)(x+1)}\,dx$. Decompose: $\dfrac{1}{(x-1)(x+1)} = \dfrac{A}{x-1} + \dfrac{B}{x+1}$. Solving: $A = 1/2$, $B = -1/2$. $= \dfrac{1}{2}\ln|x-1| - \dfrac{1}{2}\ln|x+1| + C = \dfrac{1}{2}\ln\left|\dfrac{x-1}{x+1}\right| + C$.

Worked Examples

Example 1Basic Integration

Evaluate $\displaystyle\int\!\left(3x^2 - \frac{2}{x} + e^x - \cos x\right)dx$.

1
Integrate term by term: $$= x^3 - 2\ln|x| + e^x - \sin x + C$$
Example 2FTC Part 2

Evaluate $\displaystyle\int_0^3 (x^2 + 1)\,dx$.

1
Antiderivative: $F(x) = \dfrac{x^3}{3} + x$.
2
$F(3) - F(0) = (9 + 3) - 0 = \boxed{12}$
Example 3FTC Part 1

Find $\dfrac{d}{dx}\!\left[\displaystyle\int_2^{x^2} \frac{1}{\ln t}\,dt\right]$.

1
By FTC Part 1 with chain rule: $= \dfrac{1}{\ln(x^2)} \cdot 2x = \dfrac{2x}{2\ln x} = \boxed{\dfrac{x}{\ln x}}$
Example 4U-Substitution — Indefinite

Evaluate $\displaystyle\int x^2 \sqrt{x^3+1}\,dx$.

1
Let $u = x^3+1$, $du = 3x^2\,dx$, so $x^2\,dx = \dfrac{du}{3}$.
2
$\displaystyle\int \sqrt{u}\cdot\frac{du}{3} = \frac{1}{3}\cdot\frac{u^{3/2}}{3/2} + C = \frac{2}{9}u^{3/2} + C = \boxed{\frac{2}{9}(x^3+1)^{3/2} + C}$
Example 5U-Substitution — Definite

Evaluate $\displaystyle\int_0^{\pi/2} \sin x\cos x\,dx$.

1
Let $u = \sin x$, $du = \cos x\,dx$. Bounds: $x=0 \Rightarrow u=0$; $x=\pi/2 \Rightarrow u=1$.
2
$\displaystyle\int_0^1 u\,du = \left[\frac{u^2}{2}\right]_0^1 = \boxed{\frac{1}{2}}$
Example 6Integration by Parts (BC)

Evaluate $\displaystyle\int x e^x\,dx$.

1
LIATE: $u = x$ (Algebraic), $dv = e^x\,dx$. Then $du = dx$, $v = e^x$.
2
$\int xe^x\,dx = xe^x - \int e^x\,dx = xe^x - e^x + C = \boxed{e^x(x-1) + C}$
Example 7Integration by Parts — $\int \ln x\,dx$

Evaluate $\displaystyle\int \ln x\,dx$.

1
LIATE: $u = \ln x$ (Log), $dv = dx$. Then $du = \dfrac{1}{x}dx$, $v = x$.
2
$\int \ln x\,dx = x\ln x - \int x \cdot \dfrac{1}{x}\,dx = x\ln x - \int 1\,dx = \boxed{x\ln x - x + C}$
Example 8Partial Fractions (BC)

Evaluate $\displaystyle\int \frac{3x+1}{x^2-x-2}\,dx$.

1
Factor denominator: $x^2-x-2 = (x-2)(x+1)$.
2
$\dfrac{3x+1}{(x-2)(x+1)} = \dfrac{A}{x-2} + \dfrac{B}{x+1}$. Multiply: $3x+1 = A(x+1) + B(x-2)$.
3
$x=2$: $7 = 3A \Rightarrow A = 7/3$. $x=-1$: $-2 = -3B \Rightarrow B = 2/3$.
4
$\displaystyle\int\!\left(\frac{7/3}{x-2} + \frac{2/3}{x+1}\right)dx = \boxed{\frac{7}{3}\ln|x-2| + \frac{2}{3}\ln|x+1| + C}$
